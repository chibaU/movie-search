# 🎬 Movie Search App

A simple, elegant movie search application built with **React** and **Vite**.  
Search for movies, view details, and explore ratings in a clean, responsive interface.

---

## 🔍 Overview

A lightweight movie search application that allows users to:

- 🔎 Search for movies by title
- 🎥 View movie details (rating, release year, plot)
- ⭐ See IMDb ratings and poster images
- 📱 Enjoy a responsive, mobile-friendly design

Built as a **personal portfolio project** to demonstrate:

- API integration and data fetching
- React hooks (useState, useEffect)
- Asynchronous programming
- Responsive UI design

---

## ✨ Features

- 🔍 **Real-time Search** - Search movies as you type
- 🎬 **Movie Details** - View title, year, rating, and poster
- ⭐ **IMDb Integration** - Display official ratings
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- ⚡ **Fast Performance** - Powered by Vite
- 🎨 **Clean UI** - Simple, intuitive interface

## 📦 Installation & Setup

### Steps

```bash
# Clone the repository
git clone https://github.com/chibaU/movie-search.git

# Navigate to project directory
cd movie-search

# Install dependencies
npm install

# Create .env file
cp .env.example .env

# Add your API key to .env
# VITE_OMDB_API_KEY=your_api_key_here

# Start development server
npm run dev
```

### Get Free API Key

1. Visit: https://www.omdbapi.com/apikey.aspx
2. Select "FREE" tier (1,000 daily requests)
3. Enter your email
4. Verify email and receive API key
5. Add to `.env` file: `VITE_OMDB_API_KEY=your_key`

**Important:** Never commit your `.env` file or expose your API key publicly!

### Build for Production

```bash
npm run build
npm run preview
```
